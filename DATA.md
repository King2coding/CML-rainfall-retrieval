# Data requirements

This public repository contains source code and documentation only. The
following research inputs and generated products are intentionally excluded:

- commercial microwave-link metadata and received-signal-level observations;
- rain-gauge and weather-station observations;
- MSG/SEVIRI imagery and derived cloud masks;
- ERA5 variables;
- intermediate quality-control tables and model artifacts;
- gridded and link-level rainfall estimates;
- evaluation tables, plots, logs, and operational outputs; and
- local service and deployment configuration.

Data access is governed by the applicable provider, collaborator, and project
agreements. Nothing in this repository grants redistribution rights for CML,
gauge, satellite, or ancillary datasets.

The archived scripts retain their original path assumptions. Reproduce the
expected data layout or adapt paths only in a separate working copy.
